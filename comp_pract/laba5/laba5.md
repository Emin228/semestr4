# Отчёт по лабораторной работе

## Разработка веб-приложения на FastAPI

### Цель работы

Разработать веб-приложение, способное обрабатывать GET- и POST-запросы с использованием фреймворка FastAPI.

### Используемый инструментарий

Для выполнения работы были использованы следующие средства:

- Python 3.13
    
- FastAPI — фреймворк для разработки веб-приложений
    
- Uvicorn — ASGI-сервер для запуска приложения
    
- cURL — инструмент для тестирования HTTP-запросов
    
- Веб-браузер Google Chrome (или другой браузер)
    

### Описание веб-приложения

Разработано веб-приложение «Коллекция цитат».

Приложение поддерживает следующие маршруты:

1. GET-запрос по адресу `/` возвращает приветственное сообщение.
    
2. GET-запрос по адресу `/quotes` возвращает список сохранённых цитат.
    
3. POST-запрос по адресу `/quotes` добавляет новую цитату в список.
    

### Исходный код приложения

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

quotes = [
    "Ученье — свет.",
    "Без труда не вытащишь и рыбку из пруда."
]

class Quote(BaseModel):
    text: str

@app.get("/")
def home():
    return {"message": "Добро пожаловать в коллекцию цитат!"}

@app.get("/quotes")
def get_quotes():
    return {"quotes": quotes}

@app.post("/quotes")
def add_quote(quote: Quote):
    quotes.append(quote.text)
    return {
        "message": "Цитата добавлена",
        "quote": quote.text
    }
```

### Запуск приложения

Установка зависимостей:

```bash
pip install fastapi uvicorn
```

Запуск сервера:

```bash
uvicorn main:app --reload
```

После запуска приложение доступно по адресу:

```
http://127.0.0.1:8000
```

### Демонстрация работы приложения

#### Проверка GET-запроса

В браузере открыт адрес:

```
http://127.0.0.1:8000/
```

Получен ответ:

```json
{
    "message": "Добро пожаловать в коллекцию цитат!"
}
```

#### Получение списка цитат

В браузере открыт адрес:

```
http://127.0.0.1:8000/quotes
```

Получен ответ:

```json
{
    "quotes": [
        "Ученье — свет.",
        "Без труда не вытащишь и рыбку из пруда."
    ]
}
```

#### Выполнение POST-запроса

Команда:

```bash
curl -X POST http://127.0.0.1:8000/quotes -H "Content-Type: application/json" -d "{\"text\":\"Знание — сила.\"}"
```

Ответ сервера:

```json
{
    "message": "Цитата добавлена",
    "quote": "Знание — сила."
}
```

После повторного обращения к маршруту `/quotes` новая цитата отображается в списке.
