# Отчет по лабораторной работе

## Разработка веб-сервиса для работы с изображениями на Flask

---

### 1. Цель работы

Разработать веб-сервис на базе фреймворка Flask, реализующий два эндпоинта:
- Получение логина автора
- Определение размеров PNG-изображения, переданного в запросе

---

### 2. Используемые технологии

| Компонент | Назначение |
|-----------|-----------|
| Python 3 | Язык программирования |
| Flask | Веб-фреймворк для создания REST API |
| Pillow (PIL) | Библиотека для работы с изображениями |
| io | Модуль для работы с потоками данных |

---


### 4. Описание эндпоинтов

#### 4.1 GET /login

**Назначение:**  
Возвращает идентификатор автора в формате JSON.

**Пример ответа:**
```json
{
  "author": "155291"
}
```

---

#### 4.2 POST /size2json

**Назначение:**  
Принимает PNG-изображение и возвращает его размеры в пикселях.

**Параметры запроса:**
- `image` — файл изображения (multipart/form-data)

**Возможные ответы:**

| Условие | Ответ |
|---------|-------|
| Файл передан и является PNG | `{"width": <число>, "height": <число>}` |
| Файл отсутствует | `{"result": "invalid filetype"}` |
| Файл не является PNG | `{"result": "invalid filetype"}` |
| Ошибка при чтении файла | `{"result": "invalid filetype"}` |

**Пример успешного запроса:**
```bash
curl -X POST -F "image=@photo.png" http://localhost:5000/size2json
```

**Пример ответа:**
```json
{
  "width": 800,
  "height": 600
}
```

---
