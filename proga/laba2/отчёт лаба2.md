# Отчёт по заданию: реализация паттерна «Декоратор»

  

## Цель работы

  

Реализовать программу на языке Python с использованием паттерна проектирования **«Декоратор»**.

  

Программа должна:

  

- получать исходные данные;

- возвращать данные в форматах **JSON**, **YAML**, **CSV**;

- использовать общий интерфейс через `ABC` и `@abstractmethod`.

  

## Краткое описание задания

  

В задании требуется создать структуру классов, где базовый компонент получает данные, а декораторы изменяют формат результата, не меняя код самого компонента.

  

В качестве источника данных используется открытый JSON-файл с курсами валют:

  

```text

https://www.cbr-xml-daily.ru/daily_json.js

```

  

## Используемый паттерн проектирования

  

В работе используется паттерн **«Декоратор»**.

  

Паттерн «Декоратор» позволяет динамически добавлять объекту новое поведение без изменения его исходного класса. В данной программе конкретный компонент получает данные, а декораторы преобразуют эти данные в разные форматы.

  

## Структура программы

  

В программе используются следующие классы:

  

| Класс | Назначение |

|---|---|

| `Component` | Абстрактный интерфейс компонента |

| `ConcreteComponent` | Получает данные с сайта ЦБ РФ |

| `Decorator` | Базовый класс декоратора |

| `JsonDecorator` | Возвращает данные в формате JSON |

| `YamlDecorator` | Возвращает данные в формате YAML |

| `CsvDecorator` | Возвращает данные в формате CSV |

  

## Реализация интерфейса

  

Для создания общего интерфейса используется модуль `abc`.

  

Класс `Component` является абстрактным. В нём объявлен абстрактный метод `operation()`:

  

```python

from abc import ABC, abstractmethod

  
  

class Component(ABC):

    @abstractmethod

    def operation(self):

        pass

```

  

Все остальные классы работают через этот интерфейс. Это позволяет клиентскому коду не зависеть от конкретной реализации.

  

## Полный код программы

  

```python

import csv

import io

import json

from abc import ABC, abstractmethod

from typing import Any

  

import requests

import yaml

  
  

class Component(ABC):

    """

    Общий интерфейс компонента.

    Все конкретные компоненты и декораторы должны реализовывать operation().

    """

  

    @abstractmethod

    def operation(self) -> Any:

        pass

  
  

class ConcreteComponent(Component):

    """

    Конкретный компонент получает исходные данные с сайта ЦБ РФ

    и возвращает их в виде словаря Python.

    """

  

    def operation(self) -> dict:

        url = "https://www.cbr-xml-daily.ru/daily_json.js"

  

        response = requests.get(url, timeout=10)

        response.raise_for_status()

  

        return response.json()

  
  

class Decorator(Component):

    """

    Базовый декоратор хранит ссылку на объект Component

    и делегирует ему выполнение operation().

    """

  

    def __init__(self, component: Component) -> None:

        self._component = component

  

    @property

    def component(self) -> Component:

        return self._component

  

    def operation(self) -> Any:

        return self._component.operation()

  
  

class JsonDecorator(Decorator):

    """

    Декоратор преобразует данные в JSON-строку.

    """

  

    def operation(self) -> str:

        data = super().operation()

        return json.dumps(data, ensure_ascii=False, indent=4)

  
  

class YamlDecorator(Decorator):

    """

    Декоратор преобразует данные в YAML-строку.

    """

  

    def operation(self) -> str:

        data = super().operation()

        return yaml.safe_dump(data, allow_unicode=True, sort_keys=False)

  
  

class CsvDecorator(Decorator):

    """

    Декоратор преобразует данные о валютах в CSV-строку.

    """

  

    def operation(self) -> str:

        data = super().operation()

  

        output = io.StringIO()

        writer = csv.writer(output)

  

        writer.writerow(["Code", "Name", "Nominal", "Value", "Previous"])

  

        for code, valute in data.get("Valute", {}).items():

            writer.writerow([

                code,

                valute.get("Name", ""),

                valute.get("Nominal", ""),

                valute.get("Value", ""),

                valute.get("Previous", "")

            ])

  

        return output.getvalue()

  
  

def client_code(component: Component) -> None:

    """

    Клиентский код работает с любым объектом через общий интерфейс Component.

    """

  

    print(component.operation())

  
  

if __name__ == "__main__":

    source = ConcreteComponent()

  

    print("===== JSON =====")

    client_code(JsonDecorator(source))

  

    print("\n===== YAML =====")

    client_code(YamlDecorator(source))

  

    print("\n===== CSV =====")

    client_code(CsvDecorator(source))

  

```

  

## Описание работы программы

  

Сначала создаётся объект базового компонента:

  

```python

source = ConcreteComponent()

```

  

Он получает данные с сайта:

  

```python

response = requests.get(url, timeout=10)

return response.json()

```

  

После этого объект можно обернуть в нужный декоратор:

  

```python

JsonDecorator(source)

YamlDecorator(source)

CsvDecorator(source)

```

  

Каждый декоратор вызывает метод `operation()` у базового компонента, получает исходные данные и преобразует их в нужный формат.

  

## Преобразование в JSON

  

Класс `JsonDecorator` использует функцию `json.dumps()`:

  

```python

return json.dumps(data, ensure_ascii=False, indent=4)

```

  

Параметр `ensure_ascii=False` нужен для корректного отображения русских символов.



## Преобразование в YAML

  

Класс `YamlDecorator` использует библиотеку `PyYAML`:

  

```python

return yaml.safe_dump(data, allow_unicode=True, sort_keys=False)

```

  

Параметр `allow_unicode=True` позволяет корректно выводить русские символы.

 
## Клиентский код
  
Клиентский код принимает объект типа `Component` и вызывает у него метод `operation()`:


```python

def client_code(component: Component) -> None:

    print(component.operation())

```



Благодаря этому клиентский код может работать как с обычным компонентом, так и с любым декоратором.
